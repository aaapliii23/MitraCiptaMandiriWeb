## Findings

### 01 — HIGH — R-27 (UI States: empty/loading/error)
**What:** Filter galeri yang menghasilkan 0 item (kategori tanpa foto) atau galeri kosong total tidak menampilkan empty state. Saat ini `renderGallery` hanya `display:none` semua item, grid jadi kosong tanpa pesan.
**Why fail:** R-27 requires empty/loading/error. Galeri menampilkan data, jadi butuh empty state dengan sebab + aksi.
**Evidence:** `assets/js/script.js:138-153` — `matchingItems` kosong → tidak ada `galleryExpandContainer` message, `#galleryGrid` kosong.

### 02 — HIGH — R-32 (Keyboard Accessibility)
**What:** `.gallery-item` adalah `<div>` dengan `click` listener untuk lightbox, tapi tanpa `tabindex`, `role="button"`, `aria-label`, dan tanpa focus indicator visible.
**Why fail:** R-32 requires every interactive element reachable via Tab, activatable via Enter/Space, visible focus. Saat ini hanya mouse.
**Evidence:** `pages/partials/section_galeri.php:39` — `<div class="... gallery-item" data-category=...>` tanpa tabindex/role; `assets/css/style.css: gallery-item` tanpa `:focus-visible`.

### 03 — MEDIUM — R-10 (Glassmorphism dose)
**What:** `backdrop-filter: blur` dipakai di 1 elemen galeri (`+N` overlay) — PASS untuk galeri, tapi lightbox yang sama file menambah blur di backdrop + close + nav (3 elemen) saat open. Total page saat lightbox open = 4 blurred surfaces (galeri +N + lightbox backdrop/nav).
**Why borderline:** R-10 dose cap 1-2 elemen bersamaan. Lightbox adalah konteks terpisah (modal), tapi tetap dihitung jika galeri + lightbox overlap. Perlu ditulis alasan atau kurangi 1 blur.
**Evidence:** `section_galeri.php:139` `backdrop-filter: blur(3px)` (+N), `section_galeri.php:152` `backdrop-filter: blur(10px)` (backdrop), `189` dan `211` (close/nav).

### 04 — LOW — R-31 (Every Decision Must Have a Reason)
**What:** Komentar alasan `featured` sudah ada di HTML (`hierarchy: flagship`) tapi tidak di `DESIGN.md` Motif section — alasan spacing/shadow tidak tertulis 1 baris di `DESIGN.md`.
**Why:** R-31 keystone — setiap keputusan besar butuh 1 baris alasan di DESIGN.md atau dekat komponen. Saat ini alasan ada di kode, belum di DESIGN.md.
**Evidence:** `DESIGN.md` Motif menjelaskan rounded/shadow tapi tidak menyebut `shadow 0 4px 14px → 0 12px 28px` sebagai elevation marker.

### 05 — LOW — R-03 (Mobile: tap target & rhythm)
**What:** Filter `.filter-btn` tinggi visual 38px (padding 10px 24px) — di bawah 44px minimum tap target pada `<576px` dengan 4-5 tombol wrap.
**Why:** R-03 requires 44px tap target. Saat ini 38px, masih nyaman tapi di bawah threshold.
**Evidence:** `assets/css/style.css:413` `.filter-btn {padding:10px 24px}` — rendered height 38-40px.
